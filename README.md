# Color Arts

Juego de pintar por números en el navegador. Elige un color de la paleta y toca o arrastra sobre las casillas con su número hasta completar la obra.

- 6 obras: Corazón, Flor, Gato, Hongo, Cohete y Velero
- Funciona con ratón, pantalla táctil y teclado (teclas 1–9 eligen color)
- El avance se guarda en el navegador (localStorage)
- Tema claro y oscuro

## Jugar

Abre `index.html` en cualquier navegador. No necesita instalación ni servidor.

`color-arts.html` es el mismo juego sin la cabecera del documento (la versión que se publica como Artifact); `index.html` se genera a partir de él.
